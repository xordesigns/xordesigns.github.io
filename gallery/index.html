Syntax help

Any search term that's not a keyword is treated as a card name. Names are 'cleaned' for searching - special characters and numbers are transformed back into letters, so e.g. reaper will match __reapeR and ruination will match *ru1nation respectively

Use the following keywords to filter the results. You can use any number of keywords at once, separated with spaces:

  • t: - Cards of the given type; e.g. t:function or t:lambda
  • s: - Cards of the given subtype; e.g. t:Daemon or t:Coroutine
  • e: - Searches the card's full effect text for the string. Requires quotes; e.g. e:"draw" or e:"Trash 1 installed Function"
  • fe: - Searches the card's Function effect text for the string. Requires quotes; e.g. fe:"trash" will match only Functions with the word 'trash' in their Function effect
  • ie: - Searches the card's Interrupt effect text for the string. Requires quotes; e.g. ie:"draw"
  • slot: - Cards whose effects match the slot requirement. Can write multiple slots separated with slashes; e.g. slot:3 or slot:1/2
  • !<condition>: or -<condition>: - Negates the following condition, excluding cards that match it; e.g. !t:function will match all non-Function cards

Miscellaneous keywords:

  • id: - Matches the card with the specified unique ID number. Each card's ID is the same regardless of printing; e.g. id:1 will match the card __alloc(8), whether it's from the original set or reprints
  • a: - Cards with art created by the specified artist. Requires quotes; e.g. a:"SDGecko"
  • ft: - Searches the card's flavor text for the string. Requires quotes; e.g. ft:"entropy's king"
  • set: - Cards released in the specified set. Only matches the 3-letter set code (for now); e.g. set:ADO
  • is: - Cards that match the following predefined criteria:
    • basic - Cards with no subtype.
    • advanced - Cards with any subtype.
    • etr - Cards with an 'end the run' Interrupt effect. Same as ie:"End the run".
    • split - Lambdas with split effects.
    • global - Cards with a 1/2/3 effect. Same as slot:1/2/3
    • complex - Cards with additional rulings or reminder text. The latter is equivalent to e:"("
    • ...more to be added as needed

AND and OR

Keywords are additive (AND) by default, meaning they match cards that fit *all* given keywords. You can put multiple keywords in parentheses with OR between them to match *any* of those keywords instead e.g. (e:"trash" or e:"unlock") will match all cards with trash or unlock in their effect text, instead of needing both words to appear. You can also explicitly use AND in the same way for readability, but it's not mandatory since it's the default behavior.
